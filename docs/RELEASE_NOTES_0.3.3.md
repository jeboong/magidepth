# MagiMagic 0.3.3 · 자르기, 재생, 모델 준비 개선

## 바뀐 점

- **선택형 자르기:** 기본은 전체 영상입니다. ‘자르기’를 열면 썸네일 필름스트립과 양쪽 손잡이가 나타납니다. 구간을 고른 뒤 **자르기 적용**을 눌러야 내보내기에 반영됩니다. 취소·전체 영상 복원·프레임 단위 조절을 지원합니다.
- **원본 재생바 수정:** 로컬 영상의 바이트 범위 응답을 바로잡았습니다. 재생바를 움직이면 원본 프레임으로 전환하여 이전 AI 미리보기에 가려지지 않습니다. ProRes 등 호환되지 않는 코덱은 기존 FFmpeg로 재생용 사본을 준비합니다. AI 처리·출력에는 원본을 사용합니다.
- **명시적 모델 다운로드:** 필요한 AI 모델이 없는 맵은 선택 전에 **모델 다운로드**를 누릅니다. 진행률·취소·실패 재시도를 지원하며 완료 후 직접 맵을 선택합니다. 맵 선택이나 렌더가 모델을 몰래 다운로드하지 않습니다.
- **Depth 기본 포함:** 최초 MagiDepth 셋업에서 기본 이미지·영상 Depth 모델을 함께 준비합니다. 같은 고정 버전의 기존 앱/Hugging Face 캐시는 검증 후 재사용합니다. 고급 재질 4종은 같은 모델을 공유합니다.
- **시작 시 업데이트 알림:** 앱을 켜면 새 버전을 확인합니다. 새 버전·다운로드 진행률·설치 준비 알림을 표시합니다. 자동 다운로드를 꺼도 확인·알림은 유지하며, 설치·재시작은 직접 선택합니다. 작업 중 자동으로 앱을 닫지 않습니다.

## 설치

[Windows 10/11 x64 설치 파일](https://github.com/jeboong/magidepth/releases/download/v0.3.3/MagiMagic-Setup-0.3.3.exe)

기존 설정·엔진·모델과 MagiCloak 기능은 유지합니다. 현재 실행 중인 앱을 자동 교체하는 작업은 하지 않았습니다.

미서명 베타 설치본입니다. 릴리스 출처와 `SHA256SUMS.txt`, 회사 설치 정책을 확인하세요. 보안 기능을 해제하지 마세요. AI 맵은 추정값이며 MagiCloak의 실험 기능은 효과를 보장하지 않습니다.

재생 호환 사본은 최대 720p H.264이며 원본의 알파/HDR/정밀도를 보존하는 마스터 파일이 아닙니다. 원본 파일과 최종 추출 해상도에는 영향을 주지 않습니다.
