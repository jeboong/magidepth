# MagiMagic 0.3.0 · 두 얼굴의 작업실

매지코의 마법을 느껴보세요. 기존 MagiDepth가 MagiMagic으로 확장됩니다.

## 이번 업데이트

- 최신 반쪽 Depth / 반쪽 얼굴 격자 이미지를 Windows 아이콘과 온보딩에 적용.
- 첫 실행 얼굴 **왼쪽 MagiDepth / 오른쪽 MagiCloak** 선택. 마우스 hover/선택 오버레이, 키보드 접근성, 다음 버튼, 필요한 초기 셋업 안내.
- 준비된 엔진은 다시 설치하지 않고 진입. 필요한 경우 다운로드·설치 진행률, 재시도와 나중에 준비 선택 제공. 선택한 작업실을 기억합니다.
- MagiCloak **원본품질 / 표준 / 작은파일** 세 가지 출력 품질.
- 최대 **16개 수동 격자** 추가·선택·삭제. 부드러운 드래그 오버레이, 네 모서리 크기 조절, 키보드와 숫자 입력. 드래그 종료 시 정확한 결과 갱신.
- 기존 단일 수동 격자 설정은 유지하고 다중 격자 설정으로 전환 가능합니다.

## 함께 포함되는 통합 기능

- MagiDepth 이미지·영상 맵 추출과 MagiCloak 얼굴 격자를 별도 탭으로 사용.
- A 얼굴 격자 / B·C·D 실험 처리. 실험 기능 선택 시 효과가 없을 수 있음을 경고.
- 이미지·영상 혼합 배치, 프레임 미리보기, 앞/뒤 검정 패딩과 오디오 위치 동기화.
- FFmpeg/ffprobe 설치 경로 탐지·검증·재사용 및 엔진 복구 개선.
- 기존 설정·엔진·모델 캐시와 앱 업데이트 ID 유지.

수동 격자는 모든 프레임에 같은 위치로 적용됩니다. 색·선·칸 수는 격자 간 공통입니다. 원본품질은 CRF14로 시각적 손실을 줄이는 옵션이며 원본 바이트 복사나 수학적 무손실이 아닙니다.

미서명 공개 베타입니다. 회사 설치 정책과 [라이선스 고지](../THIRD_PARTY_NOTICES.md)를 확인하세요. 입력 미디어는 클라우드에 업로드하지 않으며, 특정 플랫폼의 판정 회피나 익명화를 보장하지 않습니다.

설치 파일: `MagiMagic-Setup-0.3.0.exe`
