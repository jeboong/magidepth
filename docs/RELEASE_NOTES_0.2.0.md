# MagiMagic 0.2.0 · 매지코의 작업실 확장

매지코의 마법을 느껴보세요. 기존 MagiDepth가 **MagiMagic(매지매직)**으로 확장되었습니다.

## 두 개의 작업실

- **MagiDepth:** 기존 이미지·영상 맵 추출, 프리셋, 고급 AI, 트림, 미리보기와 저장 기능 유지.
- **MagiCloak:** Seedance Cloak의 처리 코어를 통합한 새 탭. 이미지·영상 혼합 배치, 자동 얼굴 검출/추적, 수동 격자 배치, 프레임 미리보기, 6종 출력 품질과 오디오 보존.
- **A = Face Grid**, **B/C/D = 실험적 처리**. 내부 알고리즘을 바꾸지 않고 선택 버튼을 재배치했습니다. B/C/D 활성화 시 삼각형 경고와 “이 기능은 실험적 기능이며, 적용효과가 없을 수 있습니다.”를 표시합니다.
- 짧은 영상의 검은 화면 패딩을 **영상 앞 / 영상 뒤**에서 선택합니다. 기본값은 뒤이며, 선택한 최소 전체 길이까지 채웁니다. 앞 패딩에서는 오디오도 같은 시간만큼 지연합니다.
- 입력 파일 붙여넣기·드래그앤드롭, 저장 폴더 기억, 다른 이름으로 저장, 튜토리얼, 다크/라이트 UI 지원.

## 설치와 FFmpeg 개선

- 이미 설치된 FFmpeg/ffprobe를 환경 변수, PATH, 앱 캐시 및 WinGet/Scoop 경로에서 발견하고 실제 인코딩/분석으로 검증해 재사용합니다.
- 설정에 사용 중인 경로·버전·출처를 표시합니다. 호환 도구가 없을 때만 전용 배포본을 다운로드합니다.
- MagiCloak 단독 사용에는 작은 NumPy/OpenCV 엔진만 준비합니다. PyTorch/CUDA/깊이 모델은 필요하지 않습니다.
- 기존 `%APPDATA%/MagiDepth` 설정·엔진·모델 캐시 및 업데이트 ID를 유지합니다. 새 이름의 폴더에 캐시를 복제하지 않습니다.
- 엔진 복구 전에 대기 중인 워커를 종료하고, 실행 파일 경로가 바뀌면 워커를 갱신합니다.

## 검증과 주의 사항

원본 Cloak과 동일한 합성 입력에서 코어 픽셀 일치를 확인했습니다. 실제 Windows FFmpeg 영상·오디오 출력, 앞/뒤 패딩 경계, 취소·원본 보존, 기존 RTX 5070 Ti Depth 경로를 검증했습니다. 상세 범위는 [Cloak 검증](CLOAK_VERIFICATION.md)을 참고하세요.

이 버전은 **미서명 공개 베타**입니다. Windows 경고가 표시될 수 있습니다. 회사 설치 정책을 따르고 출처·체크섬을 확인하세요. 보안 기능을 비활성화하지 마세요.

MagiCloak은 익명화 또는 특정 플랫폼 판정 회피를 보장하지 않습니다. MagiDepth의 재질/깊이 맵도 추정값입니다. 고급 모델과 포팅 코드의 라이선스는 [고지](../THIRD_PARTY_NOTICES.md)를 따릅니다.

설치 파일: `MagiMagic-Setup-0.2.0.exe`
