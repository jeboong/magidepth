# MagiMagic 0.3.4 · 모델 설치 확인 멈춤 수정

## 해결한 문제

0.3.3에서 `models:catalog` / `WorkerTimeoutError`가 반복되는 원인을 수정했습니다.
설치된 모델 목록을 확인할 때 추론 모듈의 메타데이터를 가져오면서 NumPy까지 불러왔고,
Windows의 별도 작업 스레드에서 첫 네이티브 모듈 로딩이 멈추는 현상이 재현되었습니다.
시간 제한을 늘리는 대신, 모델 메타데이터를 표준 라이브러리만 사용하는 독립 모듈로 분리했습니다.

- 모델 목록 확인은 NumPy·PyTorch·추론 파이프라인을 불러오지 않습니다.
- 기존 모델의 리비전·파일·체크섬과 추론 기능은 그대로 유지합니다.
- 설치된 모델을 삭제하거나 재다운로드할 필요가 없습니다.
- 새 프로세스에서 입력 파이프를 열어 둔 실제 목록 요청과 반복 요청을 검증합니다.
- 설치본 통합 검증도 목록 응답을 실제로 받은 뒤에 통과하도록 보강했습니다.

0.3.3의 선택형 자르기, 재생바 수정, 명시적 모델 다운로드, 시작 시 업데이트 알림은 유지됩니다.
