# MagiMagic 0.3.1 · 얼굴로 바꾸는 작업실

- 기존 텍스트 탭을 최신 얼굴 이미지 기반 중앙 전환 UI로 교체했습니다. 왼쪽 MagiDepth / 오른쪽 MagiCloak, 선택·호버 오버레이와 체크 표시를 제공합니다.
- 상단바는 평소 48px로 접혀 있고 호버하면 148px로 펼쳐집니다. 작업 화면 위로 펼쳐져 영상·격자 미리보기 크기나 위치가 움직이지 않습니다.
- 접힌 상태에서는 얼굴의 선택 오버레이를 숨깁니다. 펼친 상태에서만 선택·호버 오버레이를 보여주고, MagiDepth / MagiCloak 제목을 22px로 강조합니다. 부가 문구는 제거했습니다.
- 키보드 Tab으로 접근하면 펼쳐집니다. ← / → / Home / End로 전환할 수 있으며 선택 상태와 작업 진행 상태를 보조기기에 알립니다.
- 터치처럼 호버가 없는 환경에서는 펼친 상태를 유지합니다. 동작 줄이기 설정을 지원합니다.
- 테마·가이드·설정, 기능별 작업 상태, 최근 작업실 기억과 첫 실행 온보딩은 유지됩니다.

설치 파일: `MagiMagic-Setup-0.3.1.exe`. 이 문서는 로컬 빌드 변경 기록이며 GitHub 공개 릴리스 완료를 뜻하지 않습니다.
