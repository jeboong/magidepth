# MagiMagic 0.3.2 · 커서를 따라오는 매지코

## 처음 쓰시는 분께

MagiMagic(매지매직)은 이미지·영상을 내 PC에서 처리하는 Windows 작업 도구입니다. **MagiDepth**에서 깊이·Normal·Alpha·재질 맵을, **MagiCloak**에서 얼굴 격자와 배치 처리를 사용할 수 있습니다.

- **[Windows 설치 파일 다운로드](https://github.com/jeboong/magidepth/releases/download/v0.3.2/MagiMagic-Setup-0.3.2.exe)** · 약 130MiB
- 설치 후 **시작하기 → 얼굴 왼쪽 Depth / 오른쪽 Cloak → 다음**. 필요한 엔진만 최초 셋업합니다.
- Windows 10/11 x64. Depth는 NVIDIA GPU 권장. 첫 셋업과 새 AI 모델 다운로드는 인터넷 환경에 따라 수십 분 이상 걸릴 수 있습니다. Cloak만 쓰면 대용량 Torch/CUDA 엔진이 필요 없습니다.
- Depth 기본 여유 공간 12GB 이상, 고급 모델 포함 25GB 이상 권장. 긴 영상 출력 공간은 별도입니다.

## 함께 제공되는 기능

- **MagiDepth:** 이미지·영상의 8종 맵 선택, 스피드/밸런스/디테일 프리셋, 빠른·고급 모드, 프레임 미리보기, 트림.
- **MagiCloak:** 자동 얼굴 그리드, 최대 16개 수동 격자와 모서리 크기 조절, 이미지·영상 혼합 배치, 오디오 보존(AAC 재인코딩), 앞/뒤 검정 패딩, 원본품질/표준/작은파일 내보내기.
- 드래그앤드롭, 이미지 Ctrl+V, 저장 폴더 기억, 다크/라이트 모드, 튜토리얼, 업데이트 확인.
- 호환되는 기존 FFmpeg·엔진을 감지해 재사용합니다. 입력 미디어를 서버에 업로드하지 않습니다.

## 0.3.2의 온보딩 변경

- 온보딩에 **환영합니다!** 화면을 추가했습니다. 중앙의 큰 캐릭터가 커서의 좌우·상하 방향을 따라 고개를 움직입니다.
- 기능 선택에서 캐릭터가 작아지고, 셋업 안내에서는 위쪽의 작은 크기로 정리됩니다. 세 화면이 같은 렌더러를 유지해 리소스를 다시 읽지 않습니다.
- 기존 왼쪽 MagiDepth / 오른쪽 MagiCloak 선택 테두리·체크·키보드 조작을 유지했습니다. 색상 오버레이는 움직이는 프레임의 알파를 따라 적용됩니다.
- **상단바 이미지와 동작, Windows 아이콘은 변경하지 않았습니다.**
- ProRes 알파 MOV에서 추출한 50개 포즈와 optical-flow로 정렬한 경계 프레임을 사용합니다. 원본 첫 프레임과 마지막 프레임을 반복 연결하지 않으며, 커서가 멈추면 해당 포즈에 정지합니다. 영상에 없는 새로운 3D 시점을 생성하는 기능은 아닙니다.
- 약 5.9MiB의 WebP 리소스를 앱에 포함합니다. 온보딩에서만 지연 로드하며 종료 시 디코딩 이미지와 애니메이션 루프를 해제합니다. 일반 실행에서 FFmpeg나 AI 모델은 필요하지 않습니다.
- 동작 줄이기 설정 시 정지 포즈를 사용합니다. 리소스 로딩 실패 시 기존 정지 이미지로 대체하며 기능 선택·셋업은 계속 사용할 수 있습니다.

이미 온보딩을 끝낸 사용자는 **설정 → MagiMagic 기능 다시 선택**에서 새 환영 화면을 열 수 있습니다. 기존 온보딩 완료 상태를 강제로 초기화하지 않습니다.

공급된 알파에 일부 눈동자·치아 틈·뿔의 어두운 부분까지 투명하게 빠진 영역이 있습니다. 밝은 테마에서 해당 영역이 비칠 수 있으며 원본 매트를 임의로 채우지는 않았습니다.

## 베타 안내

- **미서명 설치 파일**입니다. Windows 경고가 표시될 수 있으므로 릴리스 출처·`SHA256SUMS.txt`와 회사 설치 정책을 확인하세요. 보안 기능을 해제하지 마세요.
- AI 맵은 추정 결과입니다. Depth 출력은 8bit 무음이며, Cloak B/C/D는 실험적이어서 효과가 없을 수 있습니다. 익명화나 특정 서비스의 판정 회피를 보장하지 않습니다.
- 기존 설정·엔진·캐시는 유지됩니다. v0.1 설치본과 공개 자산은 교체하거나 삭제하지 않습니다.
