# 동료에게 보낼 메시지

MagiDepth(매지댑스) 공개 베타 공유합니다.

이미지나 영상을 넣고 Depth·Normal·Alpha·재질 맵을 선택해 PNG/MP4로 뽑는 Windows 앱입니다. 파일 드래그앤드롭, 첨부 영역에서 Ctrl+V 이미지 붙여넣기, 프레임 미리보기, 트림, 빠른/고급 프리셋을 지원합니다. 모든 추론은 내 PC에서 처리됩니다.

설치: https://github.com/jeboong/magidepth/releases/latest

릴리스의 MagiDepth-Setup EXE를 실행한 뒤 첫 실행에서 AI 엔진 설치를 눌러 주세요. 최초 엔진/모델 다운로드 때 인터넷과 여유 디스크 공간이 필요합니다. RTX 5070 Ti 16 GB에서 검증했으며 CPU는 많이 느립니다.

처음에는 **Depth + 스피드 또는 밸런스**로 테스트해 보세요. 고급 재질 AI는 더 느리고 추정값이라 원본과 영상 길이에 따라 결과가 달라집니다. 출력 MP4에는 오디오가 없습니다.

고급 Marigold 모델은 별도 이용 조건이 있으니 README의 모델 라이선스와 회사 정책도 확인해 주세요.

현재 미서명 베타이므로 Windows 경고가 표시될 수 있습니다. 회사 설치 정책에 따라 출처와 체크섬을 확인해 주세요. 오류 제보 시 개인 영상·프로젝트 경로가 공개되지 않도록 주의해 주세요.

사용법/소스: https://github.com/jeboong/magidepth
