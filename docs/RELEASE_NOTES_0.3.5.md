# MagiMagic 0.3.5 · 자르기와 미리보기 연결

자르기가 내보내기에만 적용되고 재생바에는 원본 전체가 남아 있던 문제를 수정했습니다.

- 적용하면 재생바가 선택 구간 길이로 바뀌며, 표시 시간은 해당 구간의 0초부터 시작합니다.
- 마우스 탐색, 키보드 화살표, 이전·다음 프레임 이동은 잘린 구간으로 넘어가지 않습니다.
- 선택 구간의 마지막 프레임에서 정지합니다. 다시 재생하면 선택 구간 처음부터 시작합니다.
- `자르기 적용` 상태와 원본의 시작·종료 시각을 표시합니다.
- `자르기 수정`을 열면 원본 전체에서 다시 선택할 수 있습니다. 취소하면 이전 적용 범위로 돌아갑니다.
- `전체 영상 복원`으로 자르기를 해제할 수 있습니다. 자르기는 여전히 선택 기능이며 원본 파일은 변경하지 않습니다.
- 프레임 미리보기와 내보내기는 원본 시각을 사용합니다. 재생바의 상대 시각이 잘못 전달되지 않도록 분리했습니다.
- 한 프레임 구간과 재생 중 자르기 진입도 처리합니다. 의도적인 재생 중단을 코덱 오류로 취급하지 않습니다.

0.3.4의 모델 설치 확인 멈춤 수정과 기존 모델·설정은 유지합니다.
