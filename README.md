# MagiMagic · 매지매직

**매지코의 마법을 느껴보세요**

“히히, 평평한 장면에도 속사정은 있거든.” 매지코의 로컬 이미지·영상 작업실입니다.

- **MagiDepth** — Depth·Normal·Alpha·Base Color·Metallic·Roughness·Specular·RGB 맵 추출.
- **MagiCloak** — A 얼굴 그리드, B/C/D 실험 처리, 이미지·영상 배치, 오디오 보존과 앞/뒤 검은 화면 패딩.

기존 MagiDepth 앱은 MagiMagic으로 이름이 바뀌었습니다. 두 탭은 작업 상태를 따로 유지하며, 입력 파일은 클라우드로 업로드하지 않습니다.

상단바는 평소 48px로 접히고, 마우스를 올리거나 키보드로 접근하면 펼쳐집니다. 중앙 얼굴의 **왼쪽은 MagiDepth, 오른쪽은 MagiCloak**이며 선택 오버레이와 체크 표시로 현재 작업실을 확인할 수 있습니다. 펼쳐지는 동안 미리보기 영역의 위치와 크기는 유지됩니다.

온보딩은 알파 영상 기반의 매지코가 커서를 따라보는 환영 화면으로 시작합니다. 기능 선택 오버레이는 움직이는 얼굴 위에 유지되고, 상단바 얼굴은 기존 정지 이미지 그대로입니다. 새 온보딩은 **설정 → MagiMagic 기능 다시 선택**에서도 열 수 있습니다.

## 설치와 빠른 시작

**[Windows 설치 파일과 릴리스](https://github.com/jeboong/magidepth/releases/latest)**

1. 릴리스의 `MagiMagic-Setup-X.Y.Z.exe`를 실행합니다. 관리자 권한 없이 현재 사용자 계정에 설치됩니다.
2. **환영합니다! → 시작하기**를 누르고, 얼굴 선택 화면에서 **왼쪽 MagiDepth / 오른쪽 MagiCloak**을 선택한 뒤 다음을 누릅니다. 필요한 경우 최초 셋업 안내가 이어집니다. MagiCloak은 작은 NumPy/OpenCV 엔진만, MagiDepth는 PyTorch CUDA 12.8과 깊이 모델 라이브러리를 사용합니다. 인터넷/PC 환경에 따라 수십 분 이상 걸릴 수 있으며 기존 엔진·도구는 재사용합니다. 지금 설치하지 않고 작업실을 둘러볼 수도 있습니다.
3. MagiDepth 최초 셋업은 기본 이미지·영상 Depth 모델을 함께 준비합니다. 추가 AI 맵은 **모델 다운로드**를 직접 눌러 준비를 마친 뒤 선택할 수 있습니다. 기존 고정 버전 캐시는 검증 후 재사용하며, 맵 선택·미리보기·내보내기가 몰래 다운로드를 시작하지 않습니다. 빠른 RGB·재질 근사에는 추가 모델이 필요 없고, 빠른 Normal은 기본 Depth 모델을 재사용합니다.
4. **프레임 미리보기**로 확인한 뒤 저장 폴더와 이름을 정하고 내보냅니다.

현재 설치 파일은 **코드 서명되지 않은 공개 베타**입니다. Windows SmartScreen 경고가 나올 수 있습니다. 출처와 릴리스 SHA-256을 확인하고 회사의 설치 정책을 따르세요. 보안 기능을 끄지 마세요.

## 기능

### MagiDepth · 장면의 속을 뒤집어보자

- PNG/JPG/WebP/BMP/TIFF 이미지, MP4/MOV/MKV/AVI/WebM 등 영상
- 첨부 영역 위에 마우스를 올리거나 영역에 포커스를 둔 상태에서 **Ctrl+V 이미지 붙여넣기**
- 8종 맵 다중 선택, 맵별 미리보기 탭, 원본/결과 비교 슬라이더
- **스피드 / 밸런스 / 디테일** 프리셋, 빠른 근사 / 고급 AI 모드
- 프레임 이동·원본 재생·현재 프레임 프리렌더. **자르기**를 열어 필름스트립 손잡이로 선택한 뒤 **자르기 적용**; 기본은 전체 영상이며 취소·전체 영상 복원 지원
- AI 입력 크기, 깊이 반전, 감마, 대비, Normal 강도, AI 스텝, GPU/CPU, 정밀도 조정
- PNG / H.264·HEVC MP4, 맵별 별도 파일, 원본 크기 또는 축소 출력
- 저장 폴더 기억, 다른 이름으로 저장, 결과 폴더 열기, 취소
- 다크/라이트/시스템 테마, 앱 내 튜토리얼, 업데이트 확인 및 다운로드

### MagiCloak · 얼굴에 수상한 격자 한 꼬집

[Seedance Cloak](https://github.com/jeboong/seedance-cloak)의 처리 코어를 포팅했습니다. 기존 A/B/C 수식, 그리드, 트래커, 품질 프리셋을 유지하고 데스크톱 UI를 통합했습니다.

- 이미지·영상 혼합 배치, 드래그앤드롭·첨부 영역 Ctrl+V, 썸네일, 프레임 탐색과 설정 미리보기.
- **A Face Grid** 기본 활성화: 가로/세로 칸, 선 두께·색·투명도·여백, 타원/사각형, 기울기 정렬, 교차점, 안티앨리어싱.
- 트래킹 OFF에서는 **최대 16개 수동 격자**를 추가·선택·삭제할 수 있습니다. 드래그 이동, 네 모서리 크기 조절, 방향키·숫자 입력을 지원합니다. 끄는 동안에는 즉시 배치 오버레이를 보여주고 놓으면 정확한 결과를 계산합니다. 트래킹 ON에서는 YuNet 얼굴 검출과 IOU/EMA 스무딩을 사용합니다.
- **B Adversarial / C Frequency / D Semantic** 개별·동시 선택 및 기존 강도 조절. 선택 시 “이 기능은 실험적 기능이며, 적용효과가 없을 수 있습니다.” 경고를 표시하며 얼굴 검출·매칭 회피를 보장하지 않습니다. 표시 이름만 재배치했으며 원본 코어의 A/B/C 알고리즘은 유지합니다.
- 내보내기 품질은 **원본품질 / 표준 / 작은파일**의 세 가지입니다(H.264 CRF 14/20/28). 원본품질은 시각적 손실을 줄이는 설정이지 원본 바이트 복사나 수학적 무손실을 뜻하지 않습니다. 원본 크기, FFmpeg 단일 인코딩, 오디오 유지(AAC 재인코딩), 짧은 영상의 **앞 또는 뒤**에 검은 화면·무음 패딩을 지원합니다. 기본은 뒤이며 지정한 최소 전체 길이까지 채웁니다.
- PNG/JPEG/WebP/BMP/TIFF 이미지 저장, 지원 포맷에서 알파 보존, 영상 MP4/MOV/MKV/M4V. 저장 폴더 기억·다른 이름·취소·완료 파일 열기.

본인에게 권리가 있는 미디어만 사용하세요. MagiCloak은 신원 비식별화 보장 도구가 아니며, 중요한 개인정보 보호에는 검증된 가림/삭제 절차를 함께 사용해야 합니다. [포팅 범위와 한계](docs/CLOAK_PROVENANCE.md) · [픽셀·속도 검증](docs/CLOAK_VERIFICATION.md)

### 이미 깔린 도구는 또 소환하지 않는다

FFmpeg와 ffprobe를 환경 변수 → PATH → 기존 앱 캐시·WinGet/Scoop 등에서 찾고, 실제 시험 인코딩·분석까지 통과한 설치본을 재사용합니다. 파일명이 존재하는지만 보고 선택하지 않습니다. 사용할 수 있는 짝이 없을 때만 체크섬 검증된 전용 배포본을 내려받습니다.

설정 화면에는 사용 중인 경로·버전·출처를 표시합니다. 필요하면 `MAGIMAGIC_FFMPEG_PATH` / `MAGIMAGIC_FFPROBE_PATH` 환경 변수에 각각 절대 경로를 지정하고 앱을 재시작할 수 있습니다. 기존 `FFMPEG_PATH` / `FFPROBE_PATH`도 지원합니다. 시스템 도구를 복사하거나 전역 PATH를 수정하지 않습니다.

## 어떤 모드를 쓸까요?

| 작업 | 시작점 | 한계 |
|---|---|---|
| 빠른 이미지/1프레임 Depth | 스피드 · Depth Anything V2 Small | 낮은 지연, 영상에서 프레임간 흔들림 가능 |
| 최종 영상 Depth | 밸런스 · Video Depth Anything Small | 시간 문맥 사용. 입력 크기를 높이면 느려짐 |
| 가벼운 보조 맵 초안 | 빠른 처리 | Normal은 깊이 기반 근사, 재질은 영상처리 근사 |
| Normal·재질 AI 추정 | 고급 AI · Marigold | 느림, 영상 프레임간 일관성 보장 없음 |
| 피사체 Alpha | Alpha 선택 | 빠른 모드 BiRefNet Lite / 고급 모드 Matting |

Depth는 상대 깊이이며 미터 단위가 아닙니다. Normal은 카메라 공간 맵이며 UV tangent-space 베이크가 아닙니다. 재질은 RGB로부터의 추정이고 Specular는 metal-rough 기반 F0 근사입니다. 실제 물성이나 완벽한 로토스코핑을 보장하지 않습니다. [모델/한계](docs/MATERIAL_MAPS.md)

## 시스템 요구 사항

- Windows 10/11 x64. 권장 GPU: **RTX 5070 Ti 16 GB**, 호환 NVIDIA 드라이버.
- RAM 16 GB 이상, 고급 AI 다중 맵은 32 GB 이상 권장.
- MagiDepth 기본 설치·캐시 **12 GB 이상**, 고급 모델 포함 **25 GB 이상** 여유 공간 권장. MagiCloak만 쓰면 PyTorch·CUDA·깊이 모델 다운로드가 필요 없습니다. 긴 영상의 임시 데이터와 출력 공간은 별도입니다.
- 첫 설치·새 모델·업데이트에는 인터넷이 필요합니다. 준비된 모델은 로컬 추론합니다.
- CPU 경로도 있으나 매우 느릴 수 있습니다. NVIDIA 외 GPU 가속은 제공하지 않습니다.

## 출력과 제한

**MagiDepth:** 이미지는 8-bit PNG, 영상은 8-bit MP4이며 **오디오 없이 맵별 저장**됩니다. 16-bit/EXR와 lossless 영상 시퀀스는 제공하지 않습니다. 압축 MP4는 정밀 데이터의 무손실 교환 형식이 아닙니다.

**MagiCloak:** 8-bit 이미지·영상 처리. 원본에 오디오가 있으면 유지하되 AAC로 재인코딩합니다. 홀수 크기 영상은 크기를 변경하지 않고 YUV444로 인코딩하므로 일부 재생기에서 호환성이 낮을 수 있습니다. 배치 취소·실패 시 이미 완료된 파일은 남고, 진행 중인 임시 파일은 정리됩니다. 수동 격자는 정규화된 고정 위치로 모든 프레임에 적용하며 자동 트래킹과 구분됩니다. 여러 격자는 위치·크기가 독립적이고 색·선·칸 수 설정은 공통입니다.

다중 맵은 `장면_depth.mp4`, `장면_normal.mp4`처럼 저장합니다. 기존 파일과 원본을 덮어쓰지 않으며 충돌 시 새 이름을 선택해야 합니다. Trim은 시작 프레임 포함/종료 제외, 최근접 프레임에 맞춥니다. 가변 FPS는 평균 FPS의 고정 FPS로 출력합니다.

프레임 미리보기와 최종 영상은 정규화 범위가 달라 약간 다를 수 있습니다. 고급 재질/Alpha/Normal은 프레임별 모델이어서 흔들림이 생길 수 있습니다. **모든 모델 중 가장 빠르다는 주장은 하지 않습니다.** [선정 비교](docs/MODELS.md) · [실측](backend/BENCHMARKS.md)

## 업데이트와 개인정보

실행할 때마다 GitHub Releases에서 새 버전을 확인하고 앱 안에 알림을 표시합니다. **업데이트 자동 다운로드**를 끄더라도 확인·알림은 유지되고 다운로드만 직접 선택합니다. 설치·재시작은 사용자가 선택하며 렌더·모델 준비·미리보기 작업 중에는 막습니다. 다운로드 후 앱을 닫는 것만으로 자동 설치하지 않습니다. 이름이 바뀌어도 `%APPDATA%/MagiDepth`의 설정·모델·엔진을 재사용합니다. 기존 설치 ID와 GitHub 업데이트 주소도 유지하며, 캐시를 새 이름의 폴더로 복제하지 않습니다.

원본 재생은 바이트 범위 요청을 지원합니다. ProRes 등 내장 플레이어가 재생하지 못하는 코덱은 기존 FFmpeg로 호환 미리보기(최대 720p)를 만들고 캐시합니다. 이 재생용 사본은 색·알파·정밀도 확인용 원본이 아니며, AI 프레임 미리보기와 내보내기는 항상 원본 파일을 사용합니다. 준비 진행률·취소·재시도를 지원합니다.

미디어는 업로드하지 않지만 다운로드 서버에는 IP 등 일반 요청 정보가 전달됩니다. 앱 자체 광고/분석 텔레메트리는 없습니다. [개인정보](PRIVACY.md) · [라이선스 고지](THIRD_PARTY_NOTICES.md)

자체 앱 소스는 MIT이며 포팅된 Cloak 코어, 브랜드 이미지와 외부 모델은 별도 고지를 따릅니다. 고급 Marigold 가중치는 CreativeML OpenRAIL++-M 제한이 적용됩니다. Upstream Cloak은 명시된 공개 라이선스가 없으므로 이 저장소의 MIT를 해당 코드의 재라이선스 허가로 해석하지 마세요.

## 개발

```powershell
npm ci
npm run prepare:resources
npm run build:icon
npm run build
npm run desktop:dev
```

실시간 UI: 한 터미널에서 `npm run dev`, 다른 터미널에서 `$env:DEPTHDESK_DEV_URL='http://127.0.0.1:5173'; npm run desktop:dev`. `DEPTHDESK_*`와 `window.depthdesk`는 내부 호환 이름입니다. 브라우저만 열면 **UI 데모**이며 AI는 Electron에서만 실행됩니다.

```powershell
npm test
python -m pip install numpy==2.2.6 opencv-python-headless==4.11.0.86 Pillow==11.2.1
npm run test:backend
npm run dist:win
```

설치 파일은 `release/`에 생성됩니다. 개인 미디어·출력·가중치·캐시는 Git에서 제외됩니다. [백엔드](backend/README.md) · [배포](docs/RELEASING.md)
